# Second Post Example

This is another sample post to show how multiple entries look.

## Checklist for new posts

1. Create a file in `blog/_posts/`
2. Name it like `YYYY-MM-DD-your-title.md`
3. Add front matter with `title` and `date`
4. Commit and push to GitHub

That is it. GitHub Pages will render it automatically when Jekyll is enabled.
